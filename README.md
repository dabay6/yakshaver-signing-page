# yakshaver signing page

The built signing page of [yakshaver](https://github.com/dabay6/yakshaver), served by GitHub Pages at
<https://yakshaver.dabay6.com>. It shows an owner move that `yak` asks the owner to approve, has the owner's passkey
sign it, and hands the signature back.

Nothing in this repository is edited by hand: each release of the page's package, `packages/signing-page` in
`dabay6/yakshaver`, replaces its contents. Read, review and report on the source there.
